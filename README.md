# Norsk fra nul

Een volledig statische, dependencyvrije mini-app voor één dagelijkse Noorse zin.

Open `index.html` in een browser of gebruik dat bestand als screenshotbron in
TRMNL. Er is geen installatie, server of buildstap nodig.

De selectie gebruikt de datum in Oslo en is dus de hele dag stabiel. `app.js`
bouwt een corpus van precies 1.000 korte vertalingen in de browser.
